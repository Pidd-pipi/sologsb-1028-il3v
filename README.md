# 组件规范与无障碍说明编辑台（sologsb-1028）

面向设计系统维护者的组件契约编辑台。项目从零搭建，不是单页占位稿；组件、属性、状态、键盘行为、读屏说明、禁用场景和代码示例均使用真实数据模型，并自动保存到浏览器 `localStorage`。

## 核心机制：依赖账本

基础组件改契约时，关联组件里的组合示例与读屏说明不再可能悄悄保留旧属性名：

- **记账**：每笔契约改动都记录契约版本（语义化版本 + revision + 分支）、改动来源（面板编辑/分支管理/旧数据导入）、改动类型（属性改名 / 属性移除 / 键盘行为变化 / 分支改名）与全部受影响的引用关系（`ledger.ts`）。
- **立即失效重算**：属性改名、移除或交互签名（键盘行为）变化后，沿引用链（含跨组件的组合示例，如示例里用了 `<sp-button>`）立即重建引用目标并挂出失效提案；示例状态、复制按钮、规范检查同步刷新。
- **自动迁移并留下来源**：可 1:1 映射的改名（如 `type` → `variant`）立即生成迁移草案，只改属性区不误伤标签文本，并在引用上盖来源章（旧名、旧分支、旧 revision、账本条目）；**用户选定前不写入正式内容**，可"搁置"回退草案。
- **分支改名 / 不兼容：并列保留**：契约分支改名视为不兼容，旧示例代码与旧文档以 legacy 变体并列保留，不覆盖当前内容。
- **发布闸门**：待核对项、失效引用、未选定提案没处理完，不能保存正式版本；已搁置但旧引用仍残留在代码/文档里也会继续拦截。保存时按是否含不兼容改动自动递增 major/minor 契约版本并结清挂账。
- **旧数据先标待核对**：缺少依赖账本信息的历史数据（示例、键盘行为说明、读屏说明）一律先进入"待核对"，引用关系只按代码推断；人工核对通过后才会参与失效计算与正式保存。
- **复制保护**：处于失效或待核对状态的示例，复制按钮会拦截，避免发布后复制代码报错。

## 功能

- 组件目录与全文搜索：可搜索组件名称、属性、键盘行为、读屏说明和示例代码。
- 分组编辑器：概述、属性与状态、无障碍、关联示例、依赖账本与版本五个工作区。
- 规范校验：检测重复属性、缺少键盘/读屏说明、空示例，以及待核对引用、失效引用和未选定迁移提案。
- 迁移提案：自动迁移（改名）、人工重算（移除、键盘变化）、并列保留（分支改名）三种模式，支持"全部选定自动迁移"。
- 版本差异：正式保存后可比较字段、属性与示例变化；保留最近 12 个快照。
- 主题与密度预览：支持浅色/深色，以及紧凑、标准、宽松三档密度。
- 代码示例复制与离线编辑：内容写入本地存储，刷新或断网后仍可继续编辑。
- 撤销重做：支持工具栏按钮，以及 `Cmd/Ctrl+Z`、`Shift+Cmd/Ctrl+Z`。
- 键盘流程：`Cmd/Ctrl+K` 聚焦搜索，`Alt+1` 至 `Alt+5` 切换编辑区，`Alt+N` 新建组件，`Cmd/Ctrl+S` 保存正式版本（受发布闸门约束）。

## 技术栈

- Lit 3
- TypeScript 5
- Spectrum Web Components
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认在源码配置的 Vite 端口运行，并监听 `0.0.0.0`。宿主机端口由项目根目录的 docker-compose.yml 统一映射为 `10028:80`。

## 类型检查与生产构建

```bash
npm run typecheck
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1028 .
docker run --rm -p 10028:80 sologsb-1028
```

镜像采用 Node 多阶段构建，最终由 nginx 提供静态内容并监听容器 `80`。容器不硬编码宿主端口。

## 数据说明

浏览器存储键为 `sologsb-1028-workspace-v1`。载入旧版本数据时会自动执行一次迁移：补齐契约版本、分支、元素标签，并把缺少依赖信息的示例与无障碍文档标记为"待核对"。清除站点数据会恢复到内置示例数据（含一条 `type → variant` 的基础组件改名挂账，用于演示组合示例沿引用链失效与自动迁移）。

# 组件规范与无障碍说明编辑台（sologsb-1028）

面向设计系统维护者的组件契约编辑台。项目从零搭建，不是单页占位稿；组件、属性、状态、键盘行为、读屏说明、禁用场景和代码示例均使用真实数据模型，并自动保存到浏览器 `localStorage`。

## 功能

- 组件目录与全文搜索：可搜索组件名称、属性、键盘行为、读屏说明和示例代码。
- 分组编辑器：概述、属性与状态、无障碍、关联示例、版本与迁移五个工作区。
- 规范校验：检测重复属性、缺少键盘/读屏说明、空示例、失效属性引用和交互契约变化。
- 依赖账本：记录每个组件的契约版本、契约改动来源（直接改动 / 级联改动）以及跨组件引用关系；组合示例代码中的标签属性（含布尔属性）和读屏说明中的属性名都会被扫描登记。
- 失效传播与迁移：属性改名、移除或键盘行为变化后，沿引用链立即失效重算——能沿改名记录唯一映射的旧引用自动改写正式内容（示例代码、读屏说明）并在引用上留存迁移来源；同一旧名出现并行去向时并列保留候选（待选定），版本不兼容时保留候选，用户选定前不写正式内容；第二（或更深）层引用在自动迁移后标记“传递失效待核对”。
- 旧数据规整：首次加载或检测到缺少账本的旧数据时，扫描出的跨组件引用统一标记“待核对（旧数据）”，核对通过后才按改名记录重算。
- 发布闸门：待核对、待选定、不兼容、传递失效等待整理项，或失效示例、校验错误未清零前，不能保存正式版本；有未决引用的示例禁止复制代码，避免发布出去的代码报错。
- 版本差异：保存快照后可比较字段、属性与示例变化；保留最近 12 个快照。
- 主题与密度预览：支持浅色/深色，以及紧凑、标准、宽松三档密度。
- 代码示例复制与离线编辑：内容写入本地存储，刷新或断网后仍可继续编辑。
- 撤销重做：支持工具栏按钮，以及 `Cmd/Ctrl+Z`、`Shift+Cmd/Ctrl+Z`。
- 键盘流程：`Cmd/Ctrl+K` 聚焦搜索，`Alt+1` 至 `Alt+5` 切换编辑区，`Alt+N` 新建组件，`Cmd/Ctrl+S` 保存版本（待整理项未清零时会被拦截并说明原因）。

## 技术栈

- Lit 3
- TypeScript 5
- Spectrum Web Components
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认在源码配置的 Vite 端口运行，并监听 `0.0.0.0`。宿主机端口由项目根目录的 `docker-compose.yml` 统一映射为 `10028:80`。

## 类型检查与生产构建

```bash
npm run typecheck
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1028 .
docker run --rm -p 10028:80 sologsb-1028
```

镜像采用 Node 多阶段构建，最终由 nginx 提供静态内容并监听容器 `80`。容器不硬编码宿主端口。

## 数据说明

浏览器存储键为 `sologsb-1028-workspace-v1`。清除站点数据会恢复到内置示例数据。
